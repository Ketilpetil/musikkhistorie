# Musikkhistorie VG2 — Sequencerens historie

Åpne presentasjonen her: https://ketilpetil.github.io/musikkhistorie/

- Apper (radiostudio, step sequencer, tracker, TR-808), bilder og lydklipp er innebygd — fungerer offline hvis du laster ned fila.
- Videoer krever internett. Hvis en innebygd video ikke spiller (feil 153), bruk «Åpne på YouTube i ny fane»-lenken under videoen.
- Bruk helst Chrome, Edge eller Vivaldi. I Safari: klikk én gang på siden først for lyd i appene.
- Piltaster/mellomrom = neste slide.
